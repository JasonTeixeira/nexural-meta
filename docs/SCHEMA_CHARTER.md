# SCHEMA_CHARTER.md

**Nexural Federation — Schema & Contract Charter (v1.1, includes ADR-0006/0007/0008 amendments)**
**Status:** Canonical. Changes require ADR + 7-day soak. Schema breaking changes require 30-day soak.
**Owner:** Sage
**Last reviewed:** 2026-05-21
**Decay rate:** 180 days

---

## 0. Purpose

Without contracts, the federation becomes 30+ dialects within 18 months. This charter defines:

1. What's in a contract
2. How contracts are versioned
3. How breaking changes are made
4. What's enforced and where

This document governs `@nexural/schema` — the single source of truth for every shape that crosses a warehouse boundary.

**See also:** `docs/SCHEMA_AMENDMENTS.md` — consolidated reference for all schemas introduced by ADRs 0002–0008.

---

## 1. Principles

1. **One schema package. No alternates.**
2. **Zod first, JSON Schema derived.**
3. **Additive by default.** New optional fields = minor; new required = major.
4. **Discriminated unions over flags.**
5. **Explicit nullability.** Use `.optional()` or `.nullable()` deliberately.
6. **No `any`, no `unknown` in public schemas.** Use discriminated unions with extension variants if shape unknown.
7. **Strict mode.** `.strict()` on every object. Unknown keys = errors.
8. **Time is ISO 8601.** Never Unix timestamps in storage. Never timezone-naive.
9. **IDs are ULIDs or kebab-slugs.**
10. **Versioned in code, not folder structure.**

## 3. Primitives

```ts
import { z } from "zod";

export const Iso8601 = z.string().datetime({ offset: true });
export const IsoDate = z.string().regex(/^\d{4}-\d{2}-\d{2}$/);
export const Ulid = z.string().regex(/^[0-9A-HJKMNP-TV-Z]{26}$/);
export const KebabSlug = z.string().regex(/^[a-z0-9]+(?:-[a-z0-9]+)*$/);
export const TrustTier = z.enum(["public", "internal", "private-encrypted"]);
export const WarehouseStatus = z.enum(["active", "seeded", "archived", "deprecated", "merged"]);
export const SchemaVersion = z.literal(1);
export const SemverString = z
  .string()
  .regex(
    /^(0|[1-9]\d*)\.(0|[1-9]\d*)\.(0|[1-9]\d*)(?:-((?:0|[1-9]\d*|\d*[a-zA-Z-][0-9a-zA-Z-]*)(?:\.(?:0|[1-9]\d*|\d*[a-zA-Z-][0-9a-zA-Z-]*))*))?(?:\+([0-9a-zA-Z-]+(?:\.[0-9a-zA-Z-]+)*))?$/,
  );
export const RepoUrl = z
  .string()
  .url()
  .regex(/^https:\/\/github\.com\//);
export const Email = z.string().email();
export const DecayDays = z.number().int().positive().max(3650);

// Federation identifier (per ADR-0003)
export const Federation = z.enum(["factory", "lifeops"]);
```

Changing a primitive is a major version bump on `@nexural/schema`.

## 4. Core Schemas

### 4.1 `meta.yaml` — Warehouse Manifest

```ts
export const WarehouseMeta = z
  .object({
    schema_version: SchemaVersion,
    name: KebabSlug,
    tier: TrustTier,
    description: z.string().min(20).max(500),
    owner: z.string().min(1),
    created: IsoDate,
    last_reviewed: IsoDate,
    decay_rate_days: DecayDays,
    status: WarehouseStatus,
    merged_into: KebabSlug.optional(),

    // Per ADR-0003: which federation this warehouse belongs to
    federation: Federation,

    trust: z.discriminatedUnion("encryption", [
      z.object({ encryption: z.literal("none") }).strict(),
      z
        .object({
          encryption: z.literal("age+sops"),
          key_source: z.enum(["yubikey-primary", "yubikey-backup", "1password-emergency"]),
          recovery: z.string().min(1),
          filename_strategy: z.enum(["plaintext", "ulid"]),
        })
        .strict(),
    ]),

    backup: z
      .object({
        destination: z.string().url(),
        cadence: z.enum(["realtime", "hourly", "nightly", "weekly"]),
        retention_days: z.number().int().positive(),
      })
      .strict(),

    mcp: z
      .object({
        tool_prefix: KebabSlug,
        exposes: z.array(KebabSlug).min(1),
      })
      .strict(),

    cross_refs: z
      .object({
        consumes_from: z.array(KebabSlug).default([]),
        exposed_to: z
          .object({
            public: z.boolean(),
            agents: z.boolean(),
            human: z.boolean(),
          })
          .strict(),
      })
      .strict(),

    metrics: z
      .object({
        target_entries: z.number().int().nonnegative().optional(),
        target_scorecard: z.number().int().min(0).max(100).optional(),
      })
      .strict()
      .optional(),

    links: z
      .object({
        repo: RepoUrl,
        docs: z.string().url().optional(),
      })
      .strict(),
  })
  .strict()
  .refine((m) => m.status !== "merged" || !!m.merged_into, {
    message: "merged status requires merged_into target",
  })
  .refine((m) => m.tier !== "private-encrypted" || m.trust.encryption === "age+sops", {
    message: "private-encrypted requires age+sops",
  })
  .refine((m) => m.tier === "public" || !m.cross_refs.exposed_to.public, {
    message: "non-public tier cannot have exposed_to.public = true",
  });

export type WarehouseMeta = z.infer<typeof WarehouseMeta>;
```

**Validation:** pre-commit (husky) + CI (verify-all.mjs) + nightly across federation. Failure → CI red → blocks merge.

```ts
  session_id: Ulid.optional(),
});

export const ToolCallEvent = BaseEvent.extend({
  kind: z.literal("tool_call"),
  warehouse: KebabSlug,
  tool: KebabSlug,
  latency_ms: z.number().int().nonnegative(),
  ok: z.boolean(),
  error_code: z.string().optional(),
}).strict();

export const NxCommandEvent = BaseEvent.extend({
  kind: z.literal("nx_command"),
  command: KebabSlug,
  args_hash: z.string(),
  latency_ms: z.number().int().nonnegative(),
  exit_code: z.number().int(),
}).strict();

export const DecayWarnEvent = BaseEvent.extend({
  kind: z.literal("decay_warn"),
  warehouse: KebabSlug,
  days_since_review: z.number().int().nonnegative(),
  decay_rate_days: DecayDays,
  severity: z.enum(["warn", "quarantine"]),
}).strict();

export const AuditEvent = BaseEvent.extend({
  kind: z.literal("audit"),
  op: z.enum(["decrypt", "encrypt", "key_rotate", "key_lost", "key_added"]),
  warehouse: KebabSlug.optional(),
  file_ulid: Ulid.optional(),
  key_id: z.string(),
  exit: z.number().int(),
}).strict();

// Per ADR-0007
export const CostEvent = BaseEvent.extend({
  kind: z.literal("cost_event"),
  app: KebabSlug,
  recipe: KebabSlug,
  severity: z.enum(["warn", "exceeded", "circuit_break"]),
  scope: z.enum(["per_request", "per_user_day", "per_app_day"]),
  projected_usd: z.number().nonnegative(),
  cap_usd: z.number().positive(),
  user_hash: z.string().optional(),
}).strict();

export const TelemetryEvent = z.discriminatedUnion("kind", [
  ToolCallEvent,
  NxCommandEvent,
  DecayWarnEvent,
  AuditEvent,
  CostEvent,

```

**Privacy:** raw query strings and tool args are NEVER stored. Only hashes.

## 5. Versioning Rules

`@nexural/schema` follows strict semver.

| Change                    | Bump      | Example                            |
| ------------------------- | --------- | ---------------------------------- |
| Add optional field        | **minor** | `metrics.target_freshness`         |
| Add new schema            | **minor** | New event kind                     |
| Add value to string enum  | **minor** | `"benchmark"` to source_type       |
| Tighten constraint        | **major** | shorten `description` 500→200      |
| Rename field              | **major** | `last_reviewed` → `reviewed_at`    |
| Remove field              | **major** | drop `metrics.target_entries`      |
| Remove enum value         | **major** | remove `"merged"` from status      |
| Change type               | **major** | `decay_rate_days: number` → object |
| Add required field        | **major** | required `owner_pgp_fingerprint`   |
| Add cross-field invariant | **major** | `.refine()` that data may violate  |

Warehouses pin major: `"@nexural/schema": "^1.0.0"`.

## 6. Breaking Change Protocol

### Step 1: Propose (Week 0)

- ADR in `nexural-meta/docs/adr/`
- PR against `@nexural/schema` with breaking change
- 30-day soak

### Step 2: Migration tooling (Week 0-2)

- `@nexural/migrate-vN-to-vN+1` package
- `nx migrate-schema --to <version>` command
- CI mode for concurrent major versions

### Step 3: Publish + announce (Week 2)

- `@nexural/schema@N+1.0.0` published
- Migration tool published
- PRs against warehouses to bump + migrate

### Step 4: Migration window (Week 2-6)

- 4-week window of mixed-major operation
- Router supports both versions concurrently
- Daily digest tracks: "27/30 warehouses on schema v2"

### Step 5: Deprecate (Week 6)

- Drop vN support in router, mcp-base, sdk
- Leave vN published (yank is too aggressive)
- ADR → "Accepted"

## 7. Enforcement Locations

| Where                     | What                               | How                              |
| ------------------------- | ---------------------------------- | -------------------------------- |
| Warehouse pre-commit      | meta.yaml + frontmatter            | `scripts/validate.mjs` via husky |
| Warehouse CI              | All schemas + index.json freshness | `.github/workflows/ci.yml`       |
| `@nexural/mcp-base`       | MCP envelopes at runtime           | Zod parse on every req/resp      |
| `nx` CLI                  | Local cache, config                | Zod parse on load                |
| `verify-all.mjs`          | Every warehouse, nightly           | Pulls latest, re-validates       |
| `cross-refs.mjs`          | Link validity across federation    | Walks content                    |
| Router runtime            | Inbound + outbound MCP             | Middleware                       |
| Telemetry pipeline        | Every event                        | Reject + log invalid             |
| ADR creation              | ADR frontmatter                    | Pre-commit + CI                  |
| `nx forge` (per ADR-0006) | Recipe + lockfile validation       | Zod parse + signature check      |

**Rule:** if not validated, it drifts. Every interface gets a schema and an enforcement point.

## 9. Anti-Patterns (banned)

- ❌ `z.any()` or `z.unknown()` in public schemas
- ❌ String enums of length 2 — use boolean
- ❌ Magic numbers without comments
- ❌ Polymorphism via flags — use discriminated unions
- ❌ Reusing one schema for input AND output
- ❌ Embedding rich text/markdown without wrapping in a schema
- ❌ Schemas that depend on file paths
- ❌ Defaults that change behavior
- ❌ `z.string()` for structured things (email, URL, ULID, slug)
- ❌ Stringified JSON in fields

## 10. Testing

Every schema has:

1. ≥1 valid fixture
2. ≥5 named invalid fixtures
3. Round-trip test: parse → stringify → re-parse → deep equal
4. Snapshot test of generated JSON Schema
5. **Property-based test** (per ADR-0010 §2.5): `fast-check` round-trip

**Coverage target:** 100% line + branch across all schemas.
